モデル

3D モデル

ドラッグで回転、ホイールで拡大縮小、ダブルクリックで初期姿勢に戻ります。 寸法は流路幅 w_v = 1.0 mm、深さ 1.0 mm（正方形断面）。

STL は handover/cad/ にあります。すべて閉じたメッシュ （辺を共有する三角形がちょうど 2 枚）であることを確認済みです。 板モデルは 25.7 × 18.7 × 2.0 mm、ポート径 2.0 mm。

診断

何が間違っていたか

それまでは、バルブを周期配列にするために出口区間を「閉じ壁」に置き換え、 主流路を接合部の先へまっすぐ延長していました。局所形状は保っているつもりでしたが、 位相が変わっていました。

実形状（Fig.2 実測）

主流路は接合部で終わる。ループ下流枝と出口区間は同一直線 （角度差 -0.026 度、法線オフセット 0.003 w_v）。 逆流は折れ角ゼロでループへ入る。

周期版（閉じ壁）

主流路がまっすぐ続き、ループ下流枝は 48 度の側枝。 逆流はループへ入るのに 132 度曲がる必要があり、 主流路を素通りできる。

結果、周期版では φ_loop が順流 4.0 % ＞ 逆流 2.9 %（Re = 500）と 設計原理と逆になり、Di は Re とともに 1 を割って下がりました （0.9925 → 0.9678）。単発モデルではこれが逆転します。

形状

組み直した形状

左プレナム → 入口区間 → ループ → 出口区間 → 右プレナムという Fig.1 / Fig.2 どおりの 単発構成です。プレナム半径は実測 5.06 w_v（論文 R_p = 5）、左プレナムの中心は 実測 (−5.464, −0.029) w_v で、幾何から予想される (−5.475, 0) と一致します。 これはスケールの独立検証にもなっています。

Δp はプレナムの直線壁どうしの流量重み平均圧力差。 Di = Δp逆 / Δp順（同一流量）。格子は流路幅あたりのセル数で、 Gamboa 自身も 16 要素を使っています。

機構が働いているか

ループを通る質量流量の割合 φ_loop は、順流 11.5 %、逆流 17.2 %。 比は 1.49 で、逆流のほうがループへ流れています。 Gamboa 3.1 節が高 Di の前提とする条件です。周期版では 0.72 と逆でした。

離散理論値は 16 セルで約 95.6、20 セルで 95.76。誤差 0.1 %。 発散は τ が小さいこと自体ではなく、セル Reynolds 数 （Recell = 0.75 Re / 格子）が 20 を超えると起きます。 同じ τ でも周期版（体積力駆動）は安定でした。

次にやること

  • Fig.7 の目標値を実測し直した。Re = 300 の目標は 1.12 ではなく 1.162（従来の目視は実線 = ref CFD を読んでいた）。 本計算は 1.1217 で 3.5 % 低い
  • Re = 400（目標 1.252）と Re = 500（1.367）を計算中。 Re = 500 は流れ自体が非定常になるので時間平均で比べる
  • 格子依存（16 → 24）と収束判定の確認。Gamboa 自身は「要素数倍増で 4 % 未満」と報告
  • 7 月形状も同じ単発枠組みで解き、Gamboa と同条件で比較する
  • 3 次元は当面やらない。Gamboa のベンチマーク自体が 2D なので不要で、 同じ格子解像度なら計算量が約 20 倍になる。3D が要るのは Porwal（正方形断面）と Han（共役伝熱）の段階。そのときは今回の STL を外部ソルバへ渡すのが現実的
  • 熱はまだ入れない
