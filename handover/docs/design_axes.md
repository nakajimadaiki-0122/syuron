# 流路の設計軸と試験計画

作成日: 2026-09-07（三木さんの指摘を受けて）

指摘の要点

> きちんと流路の方向性を決めないといけない。参考文献に基づいて、どういった流路を
> どのような方向性で試すのか。コブ同士の角度、コブの大きさ、流路の幅の方向性を
> まず検討するべき。

記述は **[論文記載]**（原典に書いてある）、**[計算結果]**（本リポジトリの計算）、
**[推測]** を区別する。

## 0. 現状の反省

2026-09-07 に出した変種（`stair4_*`, `side4_*`）は**こぶの大きさ R だけを振っている**。
後述のとおり、**R は Gamboa 自身が最適化でほとんど動かさなかった変数**であり、
主軸ではない。位相（繋ぎ方）の対照実験としては意味があったが、
設計探索としては軸の選び方が文献に基づいていなかった。本書でそれを立て直す。

---

## 1. 無次元で考える — 「流路の幅」は独立な軸ではない

**[論文記載]** Gamboa 2.2 節は全長さを流路幅 w_v で無次元化し、
`w_v = 1, D_h = 2, U = 1/2, rho = 1, mu = 1/Re` としている。

したがって **2 次元では w_v そのものを変えても解は変わらない**。
Re と D_h に吸収されるからである。効くのは比だけ。

| 実寸の量 | 無次元の軸 | 備考 |
|---|---|---|
| 流路幅 w_v | — | 長さの基準。単独では効かない |
| こぶの外半径 R | **R / w_v** | Gamboa Table 2 は 2.35（最適）/ 2.50（参照） |
| こぶの間隔 | **gap / w_v** | Porwal は valve-to-valve 1 mm = 1 D_H |
| 流路の深さ H | **H / w_v（縦横比）** | Porwal 1.0（正方形）、Han 0.50/0.45 = 1.11 |
| 流速 U | **Re = rho U D_h / mu** | Gamboa 0–2000、Porwal 25–200、Han 50–400 |

**「流路の幅の方向性」は、実務上は次の 2 つに分解される。**

1. **断面の縦横比 H / w_v**（3 次元でのみ意味を持つ）。
   2 次元は H/w = ∞（平行平板、f·Re = 96）に相当し、
   正方形（f·Re = 56.91）とは別物である（[計算結果] `scripts/24_validate_3d.py`）
2. **製作・実測の都合で決まる絶対寸法**（w_v = 0.45 mm なら Han と同じ土俵、
   1 mm なら Porwal と同じ土俵）。無次元の物理には影響しないが、
   Re を同じにするための流量・圧損の実寸が変わる

## 2. 「こぶ同士の角度」は 2 つある。区別すること

三木さんの言う「コブ同士の角度」は、本形状では次の 2 つのどちらかになる。
**両方とも設計軸だが、意味も効き方も違う。**

### 2.1 接合角 β — ループが主流路へ吐き出す向き

**[論文記載]** Gamboa 3.1 節

> by increasing β, flow in the loop section is directed to oppose flow in the main channel

β は主流路法線から測る（β = 0 が主流路に垂直）。従属量で、X2・n・Y3 から決まる。

**[論文記載]** Table 2 が示す最適化の結果

| | X2 | n | Y3 | LENOUT | R | α | **β** | Average Di |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| reference | 1.50 | 0.990 | 0.600 | 2.00 | 2.50 | 45.0° | **8.53°** | 1.21 |
| optimized | 1.60 | 0.797 | 0.608 | 2.94 | 2.35 | 41.9° | **71.7°** | 1.50 |

**最適化で大きく動いたのは β（8.5° → 71.7°、8 倍）であって、R（2.50 → 2.35、−6 %）や
α（45 → 41.9°、−7 %）ではない。** Gamboa は 40 通りの設計変数の組、
約 1000 回の流れ場計算を費やしてこの結論に到達している[論文記載]。

**したがって第一の探索軸は β。**

**[計算結果]** 本リポジトリの実測値との対応

| 形状 | θ（主流路→ループ） | β = θ − 90 | 意味 |
|---|---:|---:|---|
| Gamboa optimized | 161.6° | **+71.6°** | 逆流に正面から対向 |
| Gamboa reference | 98.5° | +8.5° | ほぼ垂直 |
| 7 月形状 | 47.4° | **−42.6°** | **符号が逆。対向しない** |

### 2.2 段の折れ角 α — 隣り合うこぶがなす角

出口区間が主流路軸から折れる角（Gamboa は法線から 41.9°、
すなわち軸から 48.1°。[計算結果] Fig.2 実測 48.03°）。

段々流路ではこれが**隣り合うこぶの相対角**を決める。1 段おきに反転する構成では、
中心線が ±α_axis/2 = ±24.05° を往復する。α を変えると

- こぶ同士の角度（ジグザグの鋭さ）
- 逆流が「まっすぐループへ入る」度合い
- 流路の全長と占有面積

が同時に動く。**Gamboa は α をほとんど動かしていない（45 → 41.9°）**ので、
文献上の優先度は β より低い。ただし**多段化したときの効き方は Gamboa の
単発モデルでは評価されていない**ので、本研究で見る価値はある。

## 3. 位相（繋ぎ方）は連続量ではなく、符号を決める

**[計算結果]** 2026-09-06〜07。**ただし 2026-09-21 の格子対照で一部を撤回した。
下の「3.2 訂正」を必ず読むこと。**

| 構成 | 接合部 | 逆流の挙動 |
|---|---|---|
| 段々（Gamboa と同じ位相） | ループ下流枝と出口区間が**同一直線** | 折れ角ゼロでループへ入る |
| 直線 + 側面こぶ | ループ下流枝が主流路への**側枝**（48°） | 132° 曲がる必要があり素通りできる |

### 3.1 Di の実測値（Re = 100、4 段 / こぶ 4 個）

| 形状 | 2 次元 6 cells/mm | 2 次元 12 cells/mm | 3 次元 6 cells/mm |
|---|---:|---:|---:|
| `side4_small` | 0.9898 | 0.9899 | 0.9955 |
| `side4_std` | 0.9918 | 0.9931 | 0.9978 |
| `side4_large` | 0.9964 | 0.9960 | 1.0003 |
| `stair4_small` | **0.9970** | **1.0044** | 1.0201 |
| `stair4_std` | **0.9933** | **1.0031** | 1.0119 |
| `stair4_large` | **0.9946** | **1.0012** | 1.0092 |

統計誤差は Di ± 0.00002〜0.00043（Δp 窓標準偏差からの伝播）。

### 3.2 訂正 — 2 次元の段々は格子収束していない

**[計算結果]** 格子を 12 → 6 cells/mm にすると、**段々の Di は 1 をまたいで反転する**
（`stair4_std` で 1.0031 → 0.9933）。差 0.010 は統計誤差の 20 倍以上あり、
偶然ではない。一方**側面こぶは格子に鈍感**で、同じ変更での差は最大 0.0013 にとどまる。

したがって現時点で言えるのは次のとおり。

| 主張 | 状態 |
|---|---|
| `side4`（側枝位相）の Di < 1 | **確か。** 2 格子で一致し、3 次元でも同符号 |
| 2 次元 `stair4` の Di > 1 | **撤回。** 符号が格子に依存する。離散化誤差と同オーダーの量を見ていた |
| 3 次元 `stair4` の Di > 1（1.009〜1.020） | **未確定。** 効果は 2 次元の 2〜4 倍で大きいが、1 格子しか無い |

**位相が効くという筋自体は変わらない**（段々は常に側面こぶより Di が高い）が、
「段々は Di > 1」と言うには格子収束が要る。

### 3.3 これが計画に課す条件

段階 2 以降が見ようとしている Di の変化幅は 0.005〜0.05 である。
**離散化誤差がその幅より小さいことを先に示さないと、どのスイープも読めない。**
そこで段階 2 の前に次を必須とする。

| 確認 | 条件 | 状態 |
|---|---|---|
| 2 次元の格子収束 | `stair4_std`, Re = 100, cpm = 6 / 12 / 18 / 24 | 18・24 を計算中（2026-09-21 投入） |
| 3 次元の格子収束 | `stair4_std`, Re = 100, cpm = 6 / 8 | 8 を計算中（同） |

Di を 1/cpm^2 で外挿し、**cpm = 12 での誤差が 0.002 未満**であれば
段階 2 を 2 次元 cpm = 12 で回してよい。超えるなら cpm を上げるか、
Re = 300 まで上げて効果そのものを大きくする（Re = 300 の単発モデルでは
Di = 1.12 と、効果が Re = 100 の 30 倍ある）。

## 4. 交絡 — 単独で動かせない変数がある

**[計算結果]** 形状の作図規則上、次は独立に動かせない。

| 動かす量 | 一緒に動く量 |
|---|---|
| θ（= β + 90） | 弧の掃引 = θ + 90 − α。θ を 161.6 → 90° でループ長 −6.8 %、面積 −13.7 % |
| R | 円弧中心（Cx = X2 + R(1+cosθ)/sinθ）、ループ長、こぶ頂部の高さ h + 2R |
| α | 弧の掃引、出口区間の向き、段々の折れ角 |

**β の効果を主張するなら、ループ長を揃えた対照計算が要る。**
`src/gamboa.py: theta_family()` は円弧中心を固定して θ を振る版で、
交絡を減らすが消しはしない（掃引角は依然 θ に縛られる）。

## 5. 試験計画（案）

Re は Gamboa の定義（D_h = 2 w_v）。応答量は **Di、Δp 順、φ_loop** の 3 つ。
熱は入れない（README §3）。

### 段階 1: 位相の確定 — **完了**

段々（同一直線）と側面こぶ（側枝）で Di の符号が分かれることを確認済み。
以降は**段々（Gamboa 位相）を主対象**とし、側面こぶは対照として残す。

### 段階 2: β スイープ（**最優先。ただし §3.3 の格子収束が前提**）

| 項目 | 内容 |
|---|---|
| 振る量 | β = 0°, 20°, 40°, 60°, 72°（Gamboa reference 8.5° と optimized 71.7° を挟む 5 水準） |
| 固定 | R = 2.35, α = 41.9°, gap = 0, 4 段, 2 次元 |
| Re | **300**（Re = 100 では効果が立ち上がらない。Fig.7 の実測でも Re ≤ 250 は分離不能） |
| 本数 | 5 水準 × 順逆 2 = 10 本 |
| 対照 | 各 β でループ長を測り、Di 対 ループ長の相関も見る（交絡の切り分け） |
| 見込み | 1 本 40〜60 分、6 並列で 2 時間 |

**判定**: Di が β とともに単調増加すれば、Gamboa 3.1 節の主張を自分の計算で再現したことになる。

### 段階 3: Re 依存

| 項目 | 内容 |
|---|---|
| 振る量 | Re = 100, 200, 300, 400 |
| 固定 | 段階 2 の最良 β と、比較用に β = 8.5°（reference 相当） |
| 本数 | 4 × 2 形状 × 順逆 = 16 本 |
| 制約 | **Re ≥ 400 は cpm を上げないと発散**（Re_cell = 0.75 Re / cpm ≲ 20）。Re = 400 なら cpm ≥ 20 |

### 段階 4: 多段化と間隔（Porwal に合わせる）

| 項目 | 内容 |
|---|---|
| 振る量 | 段数 N = 2, 4, 8 / 間隔 gap = 0, 1, 2 w_v（**Porwal は 1 D_H = 1 mm**[論文記載]） |
| 固定 | 段階 2 の最良 β、Re = 300 |
| 見たいこと | 1 段あたりの Di が段数で変わるか（Porwal は 1 段あたり Di_p = 1.20 と報告） |

### 段階 5: 3 次元・断面の縦横比

| 項目 | 内容 |
|---|---|
| 振る量 | H / w_v = 1.0（Porwal、正方形）, 1.11（**Han の 0.50/0.45**[論文記載]）, 2.0 |
| 固定 | 段階 2 の最良 β、Re = 300 |
| 見たいこと | 2 次元（H/w = ∞、f·Re = 96）から正方形（56.91）へ移したとき、Di がどれだけ落ちるか |
| 制約 | 1 本 1〜3 時間。まず std だけで 3 水準 × 順逆 = 6 本 |

### 段階 6: こぶの大きさ（**優先度は低い**）

Gamboa が最適化でほとんど動かさなかった変数であり、
本リポジトリの 2 次元計算でも Di への効き方は 0.005 程度だった[計算結果]。
段階 2〜5 が終わってから、最良形状の周りで R = 1.9 / 2.35 / 3.0 を確認する程度でよい。

## 6. 何を測るか

| 量 | 定義 | 出典との対応 |
|---|---|---|
| Di | Δp_逆 / Δp_順（同一流量） | Gamboa Eq.(1)[論文記載] |
| Δp_順 | 順流の圧損 | ポンプ動力に直結。Gamboa は Fig.5 で別途報告 |
| φ_loop | ループを通る質量流量の割合 | Gamboa 3.1 節の「逆流時にループへ十分な流量が入ること」の定量化 |
| ループ長・面積 | 交絡の切り分け用 | — |

熱を入れる段階（Nu, PEC）は流動のベンチマークが閉じてから（README §3）。

## 7. 計算資源の制約（守るべき条件）

**[計算結果]** 本ソルバの限界。計画を立てるときに必ず考慮する。

| 制約 | 内容 |
|---|---|
| 安定限界 | 単発モデルは Re_cell = 0.75 Re / cpm ≲ 20。Re = 400 なら cpm ≥ 20 |
| 非定常 | Re ≥ 400 では流れ自体が非定常になり、定常 NS を解いた Gamboa とは土俵が違う |
| 収束判定 | Δp の窓平均に加えて**内部の質量流量のばらつき < 2e-3** を必須にした |
| 時間 | 2 次元 1 本 40〜60 分（cpm = 12）、3 次元 1 本 1〜3 時間（cpm = 6） |

**Re = 300 が「効果が見えて、かつ定常で、かつ現実的な計算時間」の最適点である。**
段階 2〜4 はすべて Re = 300 を基準にする。
