## 3. Fig. 1 の記号定義

**[論文]** Fig. 1 キャプション全文（原文）:

> Design variables for the Tesla-type valve: 1) the length of the inlet segment in forward flow X₂,
> 2) scale factor n yielding the coordinate nX₂, and 3) coordinate Y₃ that defined the outer tangent
> location of the return section of the loop segment, 4) loop outer radius R, 5) outlet segment length
> LENOUT, and (6) outlet segment angle α. The origin of coordinates is on the centerline of the inlet
> channel, one-half channel width from its left end.

### 3.1 座標系

**[論文]** 原点は入口流路の**中心線上**、入口流路の**左端から 0.5 w_v** の位置。
**[確認]** Fig. 1 に `W_v/2 = 0.5` の寸法が中心線から壁まで引かれており、
入口流路は y = −0.5 …… +0.5、中心線 y = 0。順流は +x 方向。

### 3.2 β の定義（**確定**）

**[確認]** β は「戻り流路が主流路法線となす角」である。すなわち **β = 0 が主流路に垂直**。

根拠は 2 つある。

1. **[論文]** 本文 2.3 節に reference valve について
   「The reference valve flow loop return segments intersected the main channel at
   **approximately nine degrees from perpendicular**」とあり、Table 2 の reference β = 8.53° と一致する。

2. **[確認]** 次式が Table 2 の両行を再現する。

   ```
   β = arctan( (X2 − n·X2) / (Y3 − w_v/2) )        w_v/2 = 0.5
   ```

   | Valve | X2 − nX2 | Y3 − 0.5 | 式の値 | Table 2 |
   |---|---:|---:|---:|---:|
   | Optimized | 0.3248 | 0.108 | **71.607°** | 71.7° |
   | Reference | 0.0150 | 0.100 | **8.531°** | 8.53° |

   reference は 3 桁完全一致、optimized の 0.09° 差は n・Y3 の丸め（n = 0.7955 とすると 71.7° ちょうど）で説明できる。

**[確認]** この一致から、以下も同時に確定する。

- **X2 と nX2 は「長さ」ではなく原点系の x 座標として使われている。**
  X2 を「左端 (x = −0.5) からの長さ」と解釈すると X2 − nX2 の符号が反転し、β が 58.3° となって Table 2 と合わない。
- **Y3 は中心線 (y = 0) からの y 座標である。** 上壁 (y = +0.5) からの高さと解釈すると合わない。
- 戻り流路の直線区間は 2 点
  **A = (X2, +0.5)**（上壁上の点）と **B = (n·X2, Y3)**（ループ側の外接点）を結ぶ方向を持つ。
  B は A より **上流側（−x）** にある（n < 1 のため）。

### 3.3 設計思想との整合

**[論文]** 3.1 節: 「by increasing β, flow in the loop section is directed to oppose flow in the main channel」。

**[確認]** 上の定義と整合する。戻り流路から主流路へ吐き出される流れは B→A、すなわち **+x 成分**を持つ。
逆流時の主流路は −x 方向なので、この吐き出しが主流を打ち消す。β が大きい（法線から傾く）ほど +x 成分が増える。
順流時は主流と同じ向きなので損失が増えない。これが Di を上げる仕組みである。

**[論文]** ただし同節は続けて「other details of the loop geometry need to be such that significant flow
occurs in the loop during the reverse flow period」と述べており、**逆流時にループへ十分な流量が入ること**が前提である。

### 3.4 α の定義

**[確認]** Fig. 1 で ALPHA の引出線は、**主流路軸（水平線）と出口区間の壁が交わる点**に向いており、
角度弧は水平線と出口区間の間に描かれている。したがって α は
**出口区間が主流路軸から下向きに折れる角度**。optimized で 41.9°。

**[未確定]** 角度を測る基準が「出口区間の中心線」か「上流側の壁」かは図から判別できない。
出口区間の幅が w_v で一定なら両者は平行なので角度は同じだが、**頂点の位置**（したがって出口区間の起点）が変わる。

> **[確認済み事実、2026-09-06 訂正]** 上の「主流路軸から測る」という読みは**誤り**だった。
> Fig.2 実測で出口区間の傾きは**主流路軸から 48.03 度**（両壁の直線当てはめ、残差 0.18 px）。
> これは**法線から 41.97 度**であり、Table 2 の α = 41.9 と一致する。
> したがって **α は β と同じく主流路法線から測る**。`scripts/13_fig2_topology.py` を参照。

### 3.5 LENOUT の定義

**[確認]** Fig. 1 で LENOUT の寸法線は出口区間に**平行**に、区間の外側にオフセットして引かれている。
補助線は出口区間に垂直で、上端は主流路との合流部付近、下端は右プレナムの円弧との交点付近を通る。
したがって LENOUT は**出口区間に沿った長さ**である。optimized で 2.94 w_v。

**[未確定]** 起点（合流部のどの点か。上流側壁の角か、中心線と主流路軸の交点か）と
終点（プレナム円弧との交点か、プレナムの直線壁か）が特定できていない。
2.94 w_v という短さから見て、**プレナムまでの距離であって、出口配管長ではない**。

### 3.6 R の定義

**[論文]** キャプション: 「loop outer radius R」。optimized で 2.35 w_v。

**[未確定]** 円弧の**中心座標**が Fig. 1 に描かれていない。R の引出線は外側円弧を指しているだけである。
中心は接線条件（入口流路上壁との接続、および戻り区間との接続）から決まるはずだが、
どの接線条件を課すかは図から一意に読めない。

**[未確定]** ループ流路の内側半径。流路幅が全周で w_v なら内側半径 = R − w_v = 1.35 w_v になるが、
Fig. 2 の島（内側の輪郭）は円ではなく**涙滴形**であり、内側が単一円弧でないことを示唆する。

### 3.7 プレナム

**[確認]** Fig. 1 に `R_p = 5` の記載がある。左右のプレナムはいずれも半径 5 w_v の半円で、
**直線壁側が入口／出口の境界面**（そこに BC を課す、2.2 節と一致）。

**[未確定]** プレナム中心の座標、および入口流路・出口区間がプレナム円弧のどこに接続するか。

## 4. Fig. 7（Di 対 Re）の読み取り — **最重要**

**[確認]** `docs/gamboa2005.pdf` p.343 Fig. 7 を画素座標で数値化した結果（軸: Re 0–2000、Di 1.0–2.0）。

| Re | optimized 2D CFD の Di |
|---:|---|
| 100 | **≈ 1.02（1.01–1.03）** |
| 200 | ≈ 1.07 |
| 300 | ≈ 1.12 |
| 500 | ≈ 1.37 |
| 600 | ≈ 1.48 |
| 1000 | ≈ 1.73 |
| 2000 | ≈ 1.92 |

低 Re 域では optimized と reference の CFD 曲線が図の分解能で分離できないため、
Re ≤ 150 の値には ±0.02 程度の不確かさがある。

**[確認]** Table 2 の「Average Di = 1.50」は 0 < Re ≤ 2000 にわたる加重平均であり（2.3 節の目的関数）、
**Re = 100 の値ではない**。

### 研究方針への影響

**[確認]** Gamboa 自身の 2D CFD でも **Re = 100 では Di ≈ 1.02** である。
したがって「Re = 100 で Di ≈ 1 ならソルバを疑う」という判定基準は成立しない。
Re = 100 単独では、正しい形状・正しいソルバでも Di ≈ 1 になる。

判別に使うべき Re は **500 以上**、できれば 1000–2000 である。

## 5. Fig. 2 からの逆算（2026-08-09 実施）

**Fig. 1 は模式図であり、Table 2 の最適値どおりに描かれていない。**
したがって Fig. 1 の画素比から寸法を逆算してはならない（§3.2 の β 検証も画素ではなく数値照合で行っている）。
一方 **Fig. 2（p.342）は実形状**なので、そこから逆算した。

### 5.1 抽出方法

**[確認済み事実]** Fig. 2 は optimized（実線）と reference（破線）の重ね描きだが、
連結成分ラベリングで完全に分離できた。実線は連結、破線は多数の小片に分かれるためである。

- 成分 #11 = optimized の外形輪郭
- 成分 #24 = optimized の島（涙滴形）
- 残り = reference（破線）と凡例

これを塗りつぶして流体領域を得た（連結成分 1 個、201224 画素）。

### 5.2 基準量

| 量 | 実測 |
|---|---|
| w_v | **44.50 px**（分流板の下面線 y=249.00 と主流路下壁 y=293.50 の中心線間） |
| 主流路中心線 | y = 271.25 px |
| 入口流路の左端 | x = 224 px（分流板の左端） |
| 原点 | x = 246.25 px（左端から 0.5 w_v）、y = 271.25 px |

### 5.3 位相（Fig. 2 から確定）

**[確認済み事実]** 断面走査で確定した。

- 主流路は分流板（x = 224..321、y = 249、厚みのある薄板）の下側。
- ループは島（涙滴形、x = 277..521）の周りを U 字に回る。左端は x ≈ 232 で閉じている。
- **ループの主流路への開口は 2 か所**
  1. **上流側**: 分流板の先端（x = 321）。ここが戻り流路の吐出口
  2. **下流側**: 島の下流端（x = 521）より右。ここでループ上側の枝が主流路へ合流する
- 順流（+x）では、ループへ入るには約 162 度向きを変える必要があり、ほとんど入らない。
- 逆流（−x）では、島の下流端でループへ掬い上げられ、戻り流路から +x 向きに吐き出されて
  主流に正面から対向する。**§3.3 の設計原理と完全に一致する。**

> **[確認済み事実、2026-09-06 追記]** ここで見落としていた点がある。
> 実形状では**主流路は下流側の接合部で終わり**（下壁の水平は x = 6.94 w_v まで、
> 主流路帯は x = 7.90 w_v で消える）、**ループ下流枝と出口区間は同一直線**である
> （外壁の角度差 0.026 度、法線オフセット 0.003 w_v、残差 0.18 px）。
>
> つまり逆流は「掬い上げられる」というより、**出口区間をまっすぐ上がるとそのままループに入る**。
> 主流路へ抜けるほうが 48 度曲がる必要がある。これが「逆流時にループへ十分な流量が入る」
> （§3.3 の前提）を成立させている。
>
> 周期版 `src/gamboa.py` はこの接合部を「閉じ壁 + まっすぐ続く主流路」に置き換えたため、
> 逆流がループへ入るのに 132 度曲がる必要があり、主流路をまっすぐ素通りできる。
> 実測でも φ_loop は順流 4.0 % > 逆流 2.9 %（Re=500）で設計原理と逆になっていた。
> **周期版で Gamboa の Di を再現することはできない。**

### 5.5 θ の検証（**2 種類ある。強度が違うので混同しないこと**）

#### (i) 逆算の独立検証 — Fig. 2 実測 対 Table 2 導出

**[確認済み事実]** 島の下端の直線部（戻り流路の内壁）に直線を当てた結果:

- 主流路軸から **18.755 度**下向き、直線残差 RMS 0.84 px = 0.019 w_v（142 点、x = 300..441）
- したがって **θ = 161.245 度、β = 71.245 度**

Table 2 の値から §3.2 の式で導いた **θ = 161.607 度** と **0.36 度差**。

**これが本来の検証である。** 図から直接測った値とパラメータ値からの導出が独立に一致し、
β = θ − 90 という換算基準を裏付ける。**この検証の実際の強度は 0.36 度**であり、
図の線幅（2〜3 px = 0.05〜0.07 w_v）に対応する。

#### (ii) 実装の自己整合確認 — 生成形状 対 設計値

**[確認済み事実]** `src/gamboa.py` が生成した形状の中心線から測った θ は
**161.6074 度**で、設計値 161.6074 度と**差 0.0000 度**（残差 4×10⁻¹⁶ w_v）。

**これは (i) とは検証の強度が全く違う。** 同じ θ を入力して同じ θ が出るのは当然で、
**実装が設計どおり動いていることの確認にすぎない**（作図・中心線抽出・角度測定の
経路にバグが無いことは示すが、幾何が Gamboa と合っていることは示さない）。
「完全一致」とだけ書くと検証の強度を誤認する。必ず (i) と区別して記録すること。

**幾何の正しさを支えているのは (i) の 0.36 度と §5.4 の各項目の一致であって、(ii) ではない。**

### 5.6 Fig.7 と不一致だった場合の疑い先（優先順）

**逆算の弱い箇所を、疑う順に記録しておく。**

1. **Di の定義の違い（§7）。** Gamboa Fig.7 は**プレナム込みのバルブ 1 段**の
   入口平面 → 出口平面の Δp 比。案 2 の Di_valve は直線接続区間を差し引いた値で、
   **プレナムの流入・流出損失が入っていない。** 系統差の向きは既知（後述）
2. **LENOUT の 11 % 差（§5.4）。** 周期構成では出口区間が閉じ壁に置き換わるので
   形状には現れないが、閉じ壁の長さと終端位置は LENOUT の解釈に依存する
3. **重ね合わせの非対称（§5.7）。** 生成側のはみ出しが Fig.2 側の 3.3〜4.5 倍あり、
   **生成形状が系統的に太い**可能性がある。線幅で説明できる範囲ではあるが、
   説明しきれていれば対称になるはずで、非対称は説明しきれていないことを示す
4. β の 0.36 度差（§5.5(i)）と円弧中心の 0.095 w_v 差（§5.4）

### 5.7 重ね合わせの非対称（記録）

**[計算結果]** 生成形状を Fig.2 の画素格子に載せて比較した結果:

| 基準値 | IoU | Fig.2 のみ | 生成のみ | 比 |
|---|---:|---:|---:|---:|
| Table 2 記載値 | 0.878 | 446 px | 1996 px | **4.5** |
| Fig.2 実測値 | 0.898 | 464 px | 1538 px | **3.3** |

線幅（2〜3 px）で流体マスクが細く出るなら、はみ出しは**生成側に偏る**のは正しい。
しかし 3.3〜4.5 倍という偏りは、線幅だけで説明するには大きい可能性がある。

## 7. Fig.7 の Di が何の Di か（原典確認）

**[論文記載]** Eq. (1)（p.339）:

> To optimize valve shape, diodicity Di was used as the basic measure of valve performance.
> This parameter is the ratio of the pressure drop in the reverse direction to that in the
> forward direction **at a given steady-state volume flow rate**, Di = Δp_r / Δp_f.

**[論文記載]** Fig. 7 キャプション（p.343）:

> Comparisons of calculated (CFD) and measured (EXP) Di versus Re for the optimized (opt)
> and reference (ref) Tesla-type valves.

**[論文記載]** §2.2:

> Inlet and outlet boundary conditions were applied to the straight walls of plenums, which
> were used to model actual plenums and pump chambers (see Fig. 1). The inlet condition was
> uniform velocity, and the outlet condition was zero pressure.

### 結論

**Fig. 7 の CFD Di は「プレナム込みのバルブ 1 段」である。**

- 圧力差の測定区間 = **入口プレナムの直線壁 → 出口プレナムの直線壁**
- 計算領域は Fig. 2 のとおり **プレナム + バルブ 1 段 + プレナム**。多段ではない
- 比を取る条件は**体積流量一定**。案 2 の流量一定駆動と一致する

### 案 2 で得る Di_valve との差

| | Gamboa Fig. 7 | 案 2 の Di_valve |
|---|---|---|
| 含むもの | 入口区間 + ループ + 出口区間 + プレナム流入・流出損失 | 入口区間 + ループ + 閉じ壁 |
| 含まないもの | 直線接続区間（そもそも無い） | 直線接続区間（差し引く）、プレナム |
| 比の条件 | 体積流量一定 | 質量流量一定（低 Ma なのでほぼ同じ） |

**プレナム損失は方向によらず概ね同じ大きさで正**なので、Di を 1 に近づける向きに希釈する。
したがって

```
Di_Fig7  <=  Di_valve（案 2）
```

という**系統差の向きが分かっている**。Re = 500 で Fig. 7 が 1.37 なら、
案 2 の Di_valve は **1.37 以上**になるのが整合的である。
逆に Di_valve が 1.37 を大きく下回る、あるいは 1 に近ければ不整合であり、§5.6 の順に疑う。

**この差を定量化するには、プレナムを含む単発モデルを解く必要がある。**
それには入口・出口境界条件が要り、現状 Re >= 200 で発散する（§6）。
したがって**現時点では系統差の向きだけを根拠に判定する。**

## 6. 再現計算上の障害

**[確認済み事実]** Gamboa のバルブは**周期形状ではない**。
入口プレナム → 入口区間 → ループ → 出口区間 → 出口プレナムという単発構成で、
出口区間は主流路軸から 48.8 度傾いているため、そのまま x 方向に並べても繋がらない。

したがって 7 月形状で使った周期単位セル法（`solve_flow_periodic`）を直接は適用できない。
一方、入口速度・出口圧力の境界条件を使う `solve_flow` は **Re ≥ 200 で発散する**（README §8 B-6）。

**Gamboa Fig. 7 と比較するには Re = 500 以上が必要**（Re = 100 では Di ≈ 1.02 で判別できない）
なので、次のいずれかが要る。

1. 出口境界条件を対流流出条件などに置き換えて `solve_flow` を高 Re で安定化する
2. 直線接続区間を挟んだ周期配列にして、直線区間の寄与（順逆で同一）を差し引く
3. 圧力差駆動の周期領域にして、バルブ以外の寄与を解析的に補正する

**この選択を先に決める必要がある。** 幾何ができても解けなければ比較できない。
