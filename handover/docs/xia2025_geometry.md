## 1. 計算領域と 4 構成

**[論文記載]** Table 2 と Fig. 1: ヒートシンク全体 Lx = 100 × Ly = 50 × H = 2 mm（銅）。
計算単位は幅 W = 3.54 mm の 1 本の流路。流路深さ Hch = 1.5 mm（上面から彫る。
流路の底から板の底まで 0.5 mm）。入口幅 Wch は TVM 0.31、SYMTVM 0.62。

**[論文記載]** Fig. 3 の 4 構成: SYMTVM-Forward / SYMTVM-Reverse / TVM-Forward / TVM-Reverse。
Forward は「right-in and left-out」、Reverse は「left-in and right-out」と書かれている。
Fig. 3 ではどの構成も入口が左・出口が右に描かれ、**Reverse は同じ流路を 180° 回転したもの**
である（TVM-Reverse の最初の島は上側・丸い端が右、出口は中心線より上。x 方向の鏡像なら
最初の島は下側になるので、鏡像ではない）。本モジュールは 180° 回転で作る。
SYMTVM は上下対称なので鏡像と回転は同じ。**2026-10-08 に鏡像から回転へ修正。**

## 3. 構成の読み方 **[画素計測 + 逆算]**

### 3.1 主流路は ±15° のジグザグ帯

TVM の外壁・島の縁・接続部の傾きを画素で測ると ±15.0〜15.1° で、出口の 165° と一致する。
流路幅 0.30 の帯が +15° と −15° を交互に向き、各帯の壁は島の円（R_in）に接する。

### 3.2 島の中心の高さ cy = 0.632 **[逆算]**

TVM で隣り合う島（上・下）の中心を結ぶ向きが −15° になる条件
（+15° 帯の壁が、次の島の縁と同一直線になる）から

    cy = (4.72 / 2) · tan 15° = 0.632

Fig. 4 の画素計測は TVM で ±0.60〜0.63、SYMTVM で ±0.62〜0.70。
SYMTVM の菱形の辺はこの cy から

    辺 = (2 cy cos15° − 0.30) / (2 sin15° cos15°) = 1.842

となり、ラベルの 1.84 と一致する。**これが cy = 0.632・R_in = 0.58 を採る根拠。**

### 3.3 SYMTVM の外壁長 3.75 **[逆算で一致]**

上の島 k の +75° 接点から −15° に伸びる外壁（offset R_out）が、次の上の島 k+1 の
外側円（R_out、中心は 4.72 右）に入るまでの長さは 3.748。ラベル 3.75 と一致。
最終段で y = 0.31（出口の上壁）に達するまでは 4.53（ラベル 4.36、差 0.17）。

### 3.4 入口 **[逆算で一致]**

SYMTVM: 入口上壁 y = +0.31 が最初の島の外側円に当たる x = 1.301（ラベル 1.29）。
TVM: 入口は幅 0.31 の水平流路で、x = 0.66 で +15° の帯に折れる。帯の縦幅は
0.30 / cos15° = 0.311 で入口幅 0.31 と一致。入口は y = −0.67〜−0.36（ラベル 0.65）。

### 3.5 SYMTVM の島は軸側の角が切られている **[画素計測]**

Fig. 4 の SYMTVM で、上の島の下側境界は x = 2.12 で y = +0.24 にあり、R_in = 0.58 の円
（最下点 +0.05）より高い。境界は −15° の直線で、長さは約 0.87（ラベルの 0.87）。
これは「前段から来る −15° 帯の外壁」と同じ線（中心から 0.342）で島を切ったもので、
帯が島の丸い端の下を幅 0.30 のまま通れるようにしている。本モジュールはこの線で切る
（弦の長さは 0.94。ラベル 0.87 との差 0.07 は許容した）。TVM の島は切らない。

### 3.6 合わない・決めきれないもの

| 項目 | 内容 | 採った値 |
|---|---|---|
| 島の縁の長さ | R_in = 0.58・θ = 30° なら接点から先端まで 2.165。ラベルは 2.00（TVM 島 3 は 2.31） | θ = 30° を優先、2.165 |
| 全長 | 2.12 + 9 × 4.72 + 出口の折れまで 4.6 = 49.2。出口 1.00 を足すと 50.2 > Ly = 50 | Ly = 50 で切る（出口 0.80） |
| SYMTVM の島の半径 | 縦の広がりは 0.98〜1.10 と小さく見えるが、それは軸側が弦で切られているため。切られていない上側の円弧（x = 1.55〜1.65 の交点）からは R ≈ 0.57・中心 0.62 で、ラベルと整合する。**差分ではない**（当初の「0.49〜0.55」は読み違い） | 0.58 |
| TVM 島 2 の「段差」（0.59 / 0.30） | 寸法線の引き方による見かけと判断 | 無視（涙滴） |
| SYMTVM の出口 | 最終段の菱形の右先端が出口の始点 x = 49.2 に一致 | — |

## 4. 座標の約束（2026-10-10 変更）

**Y 軸が鉛直（Y-up）**。板は XZ 平面（地面）に寝て、厚み方向が +Y。

| 方向 | 軸 | 範囲 |
|---|---|---|
| 流路の進行方向 | **+X** | 0 〜 50.0 mm |
| 流路幅の方向 | **Z** | −1.77 〜 +1.77 mm（計算単位 W = 3.54） |
| 板の厚み（鉛直） | **+Y** | 0 〜 2.0 mm。流路の底は y = 0.5、上面は y = 2.0 |

変換は X 軸まわり −90 度の回転 `(x, y, z) -> (x, z, -y)`。行列式 +1 の回転なので
三角形の向き（法線）は保たれる。実測で全ファイル 100 % の面が頂点順と法線で一致。

従来の Z 厚み版が要るときは `scripts/31_make_xia2025.py --up z`。

**DXF も同じ平面に載せてある。** LWPOLYLINE を押し出し方向 (0, −1, 0) の OCS で書き、
OCS の (u, v) = (x, −y) とした。DXF の任意軸アルゴリズムで世界座標 (u, 0, v) に写るので、
CAD 上では XZ 平面に乗り、STL と完全に重なる（検算済み: 世界座標で Y = 0、
Z は −1.51〜+1.51 で流体 STL と一致）。
**押し出し方向を読まない簡易ビューアでは y が反転した 2 次元図形に見える**（形自体は正しい）。

## 5. 出力の検査

`scripts/31_make_xia2025.py` が全モデルで次を確認する。

- 流体・ブロックとも非多様体辺 0（各辺がちょうど 2 枚の三角形に共有される）
- 流体体積 = 流路面積 × 1.5、ブロック体積 = 50 × 3.54 × 2 − 流体体積
- Reverse は Forward のメッシュを (25, 0) まわりに 180° 回転（面の向きは保たれる）。
  形状の三角形分割を回転後の多角形で直接やると、穴の橋渡しに失敗することがあるため

結果は `results/cad/cad_xia2025.json`、図は `figures/geometry/xia2025_four.png`、
`xia2025_detail.png`。
