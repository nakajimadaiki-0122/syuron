### 2026-09-06 に分かった最重要事項

**案 2（周期セル + 閉じ壁）では Gamboa は再現できない。周期化が機構を壊していた。**

Fig.2 の画素実測（`scripts/13_fig2_topology.py`）で確定した位相:

- 実形状では**主流路は接合部（x ≈ 7.9 w_v）で終わり**、流れは α だけ折れて出口区間へ入る
- **ループ下流枝と出口区間は同一直線**（外壁の角度差 0.026 度、法線オフセット 0.003 w_v）
- したがって逆流時、出口区間を上ってきた流れは**折れ角ゼロでループへ入る**

案 2 はここを「閉じ壁 + まっすぐ続く主流路」に置き換えていたため、
逆流はループへ入るのに 132 度曲がる必要があり、主流路をまっすぐ素通りできた。
実測でも φ_loop は順流 4.0 % > 逆流 2.9 %（Re=500）で、設計原理と逆になっていた。

これで案 2 の 3 つの異常（Di < 1、Re とともに低下、φ_loop が小さい）がすべて説明できる。

## 3. 次の一手（優先順）

### 3.0 Re >= 400 は非定常。まずここを片づける（2026-09-07 追記）

Re = 400 で +11 %、Re = 500 で −1.4 % と Di(Re) が単調にならなかった。
原因は収束の質で、**内部の断面流量が Re=500 で 20 % もばらついていた**
（質量が溜まり込んだ過渡状態）。収束判定にこの条件を追加済み。

- 同じ Re で格子を変えて（Re=400 を cpm=16/20/32）非定常性と格子依存を分離する
- 反復数は数倍になる。1 方向あたり半日を見込む
- それでも合わなければ、時間発展法で定常 NS の値を狙うこと自体を見直す

### 3.1 Re = 300 と Re = 500 を出す（判定の本命）

Re = 100 は Gamboa 自身が 1.02 なので判別力が弱い。**Re = 300（1.12）と 500（1.37）**で決める。

```bash
H=<repo>/handover
cd $H && ./.venv/Scripts/python.exe -u scripts/17_run_gamboa_full.py \
    --Re 300 --cpm 16 --dir fwd --save-fields > log/full_Re300_fwd.log 2>&1 &
# --dir rev も同様に別プロセスで（順逆は独立なので並列に回せる）
```

**判定**

- Di が Fig.7 の ±10 % 以内 → **Gamboa 再現が成立**。第 3 層タスク 1 が閉じる
- 大きく外れる → §3.3 の疑い先を順に潰す

### 3.2 Re = 500 は解像度を上げる必要がある

**[確認済み事実]** cpm = 16 では **Re = 500 で発散する**（`scripts/18` で確認）。
安定限界はセル Reynolds 数 Re_cell = 0.75 Re / cpm ≳ 20。

- Re = 400, cpm = 16 → Re_cell = 19（安定）
- Re = 500, cpm = 16 → Re_cell = 23（発散）
- Re = 500, cpm = 24 → Re_cell = 16（安定と予想。要確認）

`scripts/18_validate_io_bc_hiRe.py --Re 500 --cpm 24` で先に確かめてから投入すること。
cpm = 24 は cpm = 16 の 2.25 倍のセル数なので、1 方向 2〜3 時間を見込む。

### 3.3 それでも合わない場合の疑い先（優先順）

1. **LENOUT の解釈**（Table 2 の 2.94 対 Fig.2 実測 3.27、11 % 差）。
   `lenout_axis` を 2.94 にして感度を見る
2. **右プレナムの直線壁を鉛直にした逸脱**。`plenum_out="faithful"` の形状を
   傾いた BC 面で解けるようにするか、プレナムを大きくして影響を見る
3. 格子依存（cpm = 16 → 24 → 32）
4. β の 0.36 度差、円弧中心の 0.095 w_v 差

### 3.4 多段流路（作成済み・CFD 未実施）

`src/gamboa_full.py: chain()` で 2〜8 段を生成できる（`scripts/22_make_chain.py`）。
1 段おきに上下反転し、入口を +24.05 度から始めることで**平均方向が水平**になる。
段どうしの重なりが無いことを毎回検査している。

**CFD にかけるには BC 面の向きを揃える必要がある**（入口・出口が 24.05 度傾く）。
プレナムを付けるか、助走の直管を足すこと。

### 3.5 その先

- 案 2 の結果（7 月形状の Di 対 Re）は**そのまま使える**。あれは周期配列としての
  性能であって、単発バルブの Di ではない。**両者を混同しないこと**
- 7 月形状も案 1 と同じ枠組み（プレナム込み単発）で解けば Gamboa と直接比較できる
- Porwal・Han は定義の読解から。Porwal は 3D・正方形断面なので 2D での直接再現は困難
- 熱はまだ入れない

## 4. 踏むと戻れないもの（必ず読むこと）

`README.md` §8 に詳細。特に重い項目:

| # | 内容 |
|---|---|
| B-1 | `rasterize(pad=0)` にすると `np.roll` で上下が周期化して壁が消える |
| B-2 | TRT の Guo 外力項は**奇数成分を ω⁻ で緩和**する。ω⁺ を一律適用すると Δp が 33 % 過大。**速度分布の形は正しいままなので図を見ても気づけない** |
| B-6 | 旧 `solve_flow`（非平衡外挿 BC）は Re ≥ 200 で発散する。**使わない。** 単発モデルは `solve_flow_io`（Zou-He）、周期配列は `solve_flow_periodic` |
| B-7 | 周期版の収束判定は速度残差ではなく体積力 G の安定性で行う。単発版は **Δp の安定性**で行う |
| B-9 | **単発モデルの安定限界は Re_cell = 0.75 Re / cpm ≲ 20**（2026-09-06）。周期版は同じ τ で安定なので、「TRT は低 τ でも大丈夫」を単発モデルへ持ち込まないこと |
| B-10 | 正則化 BC（Latt 2008）は**本ソルバでは逆に不安定**。TRT の奇数非平衡成分を捨てるため。既定は Zou-He |
| B-11 | 入口・出口の **BC 列（i=0, nx−1）の断面流量は内部と一致しない**。質量保存は内部で見る |

## 5. 誠実さの基準（この研究で守ってきたこと）

- **「確認済み事実」「論文記載」「計算結果」「推測」を区別する**
- **未確定は未確定のまま残す**（Gamboa の LENOUT、下流側接合角など）
- **検証の強度を偽らない。** 生成形状が設計値と一致するのは実装の自己整合確認にすぎず、
  幾何の正しさは示さない（`docs/gamboa2005_geometry.md` §5.5）
- **自分の誤差を貢献に読み替えない**
- **CFD 用に入れた逸脱は必ず明示する**（右プレナムの直線壁の向きなど）

過去に 2 回、幾何の要件確認を飛ばして結果が無効化されています。
2026-09-06 の一件（周期化が位相を壊していた）で **3 回目**です。
**ベンチマークが閉じる前に新構造の提案へ移らないでください。**
